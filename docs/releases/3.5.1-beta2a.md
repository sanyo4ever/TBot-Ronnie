## Backend compatibility

Use the Go backend bundled with this exact release. The new paired route `/bot/planets/:planetID/send-system-discovery-bounded` requires `galaxy`, `system`, positive `maxFleets` and the explicit reserved `positions`. Older backends may lack it; a missing/rejected route must not trigger an unbounded fallback. Legacy-route compatibility is separate from the bounded contract. Ambiguous/partial sends require reconciliation and must not be treated as complete success.

Synthetic movement evidence cannot uniquely attribute an indistinguishable simultaneous manual action without a server request identifier. A no-replay HTTP boundary is not a universal idempotency guarantee.
