# TBot 3.5.1-beta2c

Maintenance prerelease based on Ronnie **v3.5.1-beta2**. Retains all stability changes and the exact Go backend pin from **3.5.1-beta2b**.

Upstream proposal (updated existing PR): https://github.com/ronnie32/TBot/pull/6.

## Fixed

- Automatic expeditions honor `SecondaryShip`, `SecondaryToPrimaryRatio` and `MinSecondaryToSend` again. The settings remained in the configuration after an earlier worker refactor removed their implementation.
- Both primary and additional secondary ships are shared across the selected origin's pending sends using the existing planner forecast. Secondary additions are capped by `floor(actual primary count * ratio)`. With 12 LargeCargo, 24 SmallCargo, three pending sends and ratio 2, each expedition receives 4 LargeCargo and 8 SmallCargo.
- Scarce/remainder inventory is distributed using integer ceiling division. Ratio arithmetic uses decimal values and a saturated bound; overlapping escort types cannot overdraw stock, and secondary cannot duplicate the primary type or consume its reserve.
- A positive secondary minimum prevents dispatch from that origin when the shared, ratio-capped amount is too low. Existing origin fallback remains. With minimum zero, available escorts can still fly without primary ships. Manual composition, fair rounds, origin caps, current-slot checks and dispatch safety remain unchanged.

No Go changes, new game requests or blind retry/recovery loop. Missing or `Null` SecondaryShip disables secondary composition. Missing ratio/minimum uses the public defaults 2/0. Invalid, nonmovable or identical ship types and negative ratio/minimum stop preparation for that origin with an error message. No configuration schema change is required.

## Validation

- Full .NET10 fork suite: 561 passed, 0 failed, 0 skipped.
- 33 additional offline regression cases cover sharing/remainders, ratio limits/fractions/zero/extreme values, minimum rejection and fallback, reserves/nonmutation, zero primary, optional settings, escort overlap, manual mode, origin caps, slot changes and confirmed rejection.
- The original omitted-secondary behavior was reproduced before the fix: 22 of the first 29 new cases failed, while seven compatibility cases passed.
- Independent .NET9 suite on Ronnie's unchanged release base with updated PR6: 226 passed, 0 failed, 0 skipped. No framework or Go pin change in that proposal.
- No live login, actual fleet send or running-client API was used. Existing dependency/compiler warnings remain; no dependency upgrades in this patch.

Public tag/version: `3.5.1-beta2c`; package version: `3.5.1-beta2.c`. The author base remains a beta, so this is a prerelease.
