# TBot 3.5.1-beta2d

Maintenance prerelease based on Ronnie **v3.5.1-beta2**. Retains every change from **3.5.1-beta2c**, including primary/secondary expedition sharing.

## Fixed

Legacy galaxy player-rank links use `page=highscore&searchRelId=...`, which the browser proxy forwarded unchanged. For confirmed OGame 13+ servers, the backend now adapts this GET to `page=ingame&component=highscore`, retaining the focus parameter and all ranking filters. It applies to both normal and manual transaction page access. Old/unknown versions, explicit components, modern links and POSTs retain their existing behavior.

Only 11 production lines in the Go backend change. No fleet, expedition, configuration or C# algorithm change; no extra requests or retries.

Standalone upstream proposal: [ronnie32/ogame.mod#3](https://github.com/ronnie32/ogame.mod/pull/3), based on `release/v13-beta10` (`e9f365f8`), independent of pending stability PR2. Ronnie can merge this backend patch and update TBot's Go gitlink to his resulting commit. Our fork integration is [sanyo4ever/ogame.mod#4](https://github.com/sanyo4ever/ogame.mod/pull/4), retaining all previous fixes.

Pinned backend: `5e921560dc524cd0d6caa614f6f8984ebaf135fc`.

## Validation

- 13 new offline regression cases pass: legacy v13/revision/beta routes, focus and filters, repeated/encoded query values, caller query preservation, old/unknown servers, explicit components, unrelated routes, POST, browser handler and manual transaction access.
- Five cases failed on the original code before the fix; eight compatibility cases already passed.
- Full `go test -count=1 ./...` and ogamed-tbot build pass on our backend and independently on Ronnie's release base with only this patch. Go CI passes on Windows and Linux.
- Full .NET 10 fork suite: 561 passed, 0 failed, 0 skipped.
- No live login, browser navigation, fleet action or running-client API was used. Actual live player highlighting remains an operator check. Existing dependency/compiler warnings remain; no dependency upgrades in this patch.

Public tag/version: `3.5.1-beta2d`; package version: `3.5.1-beta2.d`. The upstream base remains a beta, so this is a prerelease.
