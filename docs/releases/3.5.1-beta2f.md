# TBot 3.5.1-beta2f

Proxy manual mode now uses `General.ManualModeTimeoutSeconds` in the account's instance settings. The default is **120 seconds**, including older configurations that omit the property. Previously the backend hardcoded 30 seconds.

Set a positive integer number of seconds and restart TBot to apply it, for example:

```json
"General": {
  "ManualModeTimeoutSeconds": 120
}
```

This is an inactivity timeout: a proxied game GET or POST renews the timer, including background game requests. The manual-mode button can release it immediately. Manual mode holds automated game operations, including Defender checks, while the user controls the proxy.

The TBot startup option and ogamed backend are released together, pinning Go commit `238a478d2a70080ed6827b0ab5b3a30791e8f3f5`. Timer ownership is synchronized: an expired callback cannot release a refreshed/new session, and an in-flight proxy request retains its transaction until it finishes. All fixes from 3.5.1-beta2e, including expedition ship sharing, secondary ships, conservative fleet dispatch reconciliation and highscore navigation, are retained.
